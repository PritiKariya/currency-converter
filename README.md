# Currency Converter
-> A simple currency converter built using HTML, CSS, and JavaScript.

# Features
- Convert between different currencies
- Fetches exchange rates using an API
- Dynamic currency dropdowns
- Currency flags update automatically
- Input validation

# Technologies Used
- HTML
- CSS
- JavaScript
- Fetch API

# API
Currency exchange rates are fetched from the Fawaz Ahmed Currency API.

# How to Run
Open `index.html` in a browser.

# What I Learned
- How to use the Fetch API to get data from an external API
- How to work with JSON data
- How to use `async/await` with API requests
